Our Privacy Promise

We operate on a strict zero-data-collection policy:

  • No user accounts, logins, or email collection
  • No cookies for tracking or profiling
  • No server-side data storage or processing
  • No third-party analytics trackers (beyond basic pageview counting)
  • All inputs stay in your browser's volatile session memory
  • When you close the tab, all data is permanently destroyed

PWA / Install App

Our "Install App" feature uses standard browser Progressive Web App technology. It creates a home screen shortcut and enables offline access. It does not install any executable software, APK, or binary. No malware. No adware. Just the same website with offline caching via a Service Worker.

Export Features

All calculators support export to PDF, CSV, and XLSX. Files are generated entirely in your browser using client-side libraries (jsPDF, SheetJS). Nothing is uploaded to any server during export.

Technology Stack

Built with vanilla HTML, CSS, and JavaScript. No frameworks. No build tools. No dependencies beyond two on-demand export libraries. The entire site is inspectable in your browser's developer tools — every line of code is transparent.
