🚀 About

FinCalcHub Marketing is a comprehensive web application providing 13 professional financial calculators with live cryptocurrency conversion. All calculations run 100% client-side in the browser — no data is sent to any server.

🔧 Tech Stack

  • Frontend: Pure HTML5, CSS3, JavaScript (ES6+)
  • Styling: Tailwind CSS via CDN
  • API: CoinGecko public API (no authentication required)
  • Hosting: Netlify / Vercel (static deployment)
  • PWA: Progressive Web App with manifest.json

🚀 Deployment

Netlify

Simply drag and drop the files into Netlify, or connect your GitHub repo. The _redirects file handles routing.

Vercel

Import your GitHub repo into Vercel. The vercel.json file handles routing and headers.

Manual

Upload all files to any static hosting provider (Apache, Nginx, S3, GitHub Pages, etc.).

🔒 Privacy & Security

  • 100% Client-Side: All calculations happen in your browser
  • No Data Collection: No analytics, no cookies, no tracking
  • No Server-Side: No backend, no database, no user accounts
  • Offline Fallback: Works even if CoinGecko API is unavailable

📱 PWA Installation

FinCalcHub is a Progressive Web App. Users can install it to their home screen for instant access:

  • iOS Safari: Tap Share → Add to Home Screen
  • Android Chrome: Tap menu → Install app / Add to Home Screen
  • Desktop Chrome: Click install icon in address bar
