💾 Features Across All Calculators

💱 Global Currency

Choose from 30 display currencies. The site-wide switcher uses preset conversion factors; these are not live foreign-exchange rates.

💾 Save to Browser

Supported inputs and preferences can be saved in browser storage and restored on a later visit. Persistent values stay until you clear browser storage; session state ends with the session.

📄 Export Reports

PDF and CSV files are generated in the browser. XLSX is generated in the browser with a locally loaded SheetJS file; exports may include entered values.

📱 PWA Install

Install FinCalcHub on a supported device. The cached app shell and Simple/Scientific calculators can work offline; the other calculators and information pages need a connection.

🔒 Local Calculations

Most calculator math runs in the browser. The site also uses Google Analytics and requests crypto-price data; supported inputs may be stored locally, and share links can include input values. See the Privacy Policy.
