Privacy Policy

Last updated: October 6, 2026

This Privacy Policy describes how FinCalcHub Marketing ("FinCalcHub", "we", "us") handles information when you use our website at fincalchub.xyz.

1. Calculator Data and External Requests

Calculator inputs: Most calculator formulas run in your browser. The calculation itself does not require sending form values to FinCalcHub's calculator service. This is not a promise that the site makes no network requests: analytics, live crypto pricing, page delivery, and user-initiated sharing are separate activities described below.

Cryptocurrency prices: When prices load, the browser requests the same-origin /api/crypto-prices endpoint. The project includes a handler in api/crypto-prices.js that requests reference prices for Bitcoin, Ethereum, and Solana from CoinGecko and returns the response to the page. This design is a server-side request to CoinGecko, not a direct browser-to-CoinGecko request. CoinGecko may process request metadata from the server handling that call; the website host may process the visitor's IP address and request data for delivery, security, and operations. Cached or fallback values may be shown when current data cannot be retrieved.

Share links: The calculator Share control can place the active calculator and non-empty input/select values in the URL fragment after #. The fragment is not encrypted; anyone who receives the link can view or restore those values. Other page-share controls share the page URL. If you choose an external service such as WhatsApp, Facebook, X, or LinkedIn where offered, the URL/text is sent to that service under its own policies; copying a link places it on your clipboard. Do not include sensitive information in a shared calculation.

2. Browser Storage

When browser storage is available, the main calculator can save supported form values and display-currency preferences in localStorage, and it uses sessionStorage for some current-session inputs and the active calculator. Persistent input values have no automatic expiry; session values normally expire when the browser session ends. You can clear either store through your browser settings.

The page also stores a local crypto-price cache. It accepts that cached record as recent only when its timestamp is less than one hour old; an older record may remain in storage but is not treated as a recent price by the app. Browser storage remains subject to your browser's own settings, sync, backups, and extensions.

3. Analytics

The main calculator page loads Google Analytics through Google's tag script to measure site usage. The implementation configures anonymize_ip and disables Google Signals and ad-personalization signals. Analytics requests may include page-view and interaction data, browser/device details, referral information, and approximate location as handled by Google. IP anonymization is a configuration setting; it does not mean that every analytics signal is anonymous.

Google processes analytics data under its own privacy policy and data-processing terms. The measurement ID used by the main calculator page is G-4LEKFYK37L.

4. Hosting and Delivery

The project includes Vercel deployment configuration. The hosting, CDN, or security providers used by a live deployment may process IP addresses, request headers, and technical logs to deliver the site and protect it from abuse. The provider and its practices depend on the active deployment and network configuration; consult that provider's privacy information.

5. Cookies

FinCalcHub Marketing does not intentionally use first-party cookies for calculator inputs. Google Analytics and the active hosting or security provider may use cookies or similar technologies under their own settings and policies. Browser storage described above is separate from cookies.

6. Advertising

FinCalcHub currently does not display advertisements. If advertising services (such as Google AdSense) are implemented in the future, those services may use cookies and collect data according to their respective privacy policies. This Privacy Policy will be updated accordingly.

7. Third-Party Services and Exports

  • CoinGecko — Supplies reference crypto-price data through the site's /api/crypto-prices endpoint when available.
  • Google Fonts — The main calculator page requests the Inter typeface when its font stylesheet is loaded.
  • Font Awesome via cdnjs — Some information pages request icon styles and font files from the Cloudflare-hosted CDN.
  • Google Analytics — Measures site usage as described above.
  • Hosting and delivery providers — May process technical request data as needed to serve and protect the site.

Export generation runs in the browser. PDF is assembled by the site's JavaScript; CSV is assembled from the entered values and results by the site's JavaScript. XLSX is generated with SheetJS from the locally hosted /xlsx.mini.min.js file. The file is loaded before export use and also preloaded after a short delay. The CSV action loads the same file before running the site's built-in CSV generator. The project code does not load jsPDF, Chart.js, or a CDN-hosted SheetJS export library.

Each external provider processes data according to its own privacy policy.

8. Data Security

The site is configured to use HTTPS. Running most calculations in the browser reduces the form data sent to FinCalcHub for those calculations, but it does not eliminate analytics, hosting, crypto-price, storage, or sharing data flows. Use care with shared URLs and review the assumptions in each calculator.

9. Children's Privacy

FinCalcHub is not directed at children under 13, and we do not knowingly request personal details from children. The site’s analytics and hosting providers may process technical or usage data as described above. If you believe a child has sent us personal details, please use the contact options below.

10. Your Choices

  • You can clear localStorage and session storage through your browser settings at any time
  • You can use browser extensions to block analytics scripts
  • You can use private/incognito browsing mode to prevent persistent storage
  • You can contact us with privacy questions about information handled by FinCalcHub Marketing; third-party data is subject to the provider’s own controls and policies

11. Changes to This Policy

We may update this Privacy Policy periodically. Changes will be reflected on this page with an updated "Last updated" date. Continued use of the website after changes constitutes acceptance of the revised policy.

12. Contact

For privacy-related questions or concerns, please use the contact options on the main calculator page. Please do not send sensitive calculator inputs through a shared URL or support message.
